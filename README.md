# Double Exposure: Returning to The Old Summer Palace

An atmospheric, meditative walking game set in the ruins of Yuanmingyuan (The Old Summer Palace). Explore three scenes, touch details, and discover six observations — each unlocking a quiet moment of reflection.

## Play Now

👉 **[https://katrian021-star.github.io/Double-Exposure/](https://katrian021-star.github.io/Double-Exposure/)**

## About

*Double Exposure* is a first-person exploration experience that invites you to walk through the layered ruins of Yuanmingyuan. As you touch carved stones, watch swans, or sit on a bench by the lake, short poetic reflections unfold — fragments of a mind meeting a wounded landscape.

The game is built entirely in a single HTML file with Canvas rendering.

## Features

- **3 explorable scenes** with hand-drawn visual style
- **6 discoveries** to collect, each with original poetic text
- **Background music** tailored to each scene's atmosphere
- **Save progress** automatically via browser localStorage
- **Continue / Return Home** functionality
- **Notebook** to review collected discoveries
- **Easter egg** hidden in the ending screen

## Controls

- **Click hotspots** to interact with objects
- **Click zone exits** (arrows) to move between scenes
- **📓** Open observation notebook
- **RETURN HOME** button in bottom-right corner
- **E key** Toggle hotspot editor (debug mode)
